# P3：科室历史分析与观察候选

[English](clinical-pathway-workbench-p3-analysis.md) | 中文

状态：需求提案，待用户审阅；复用已部署的三工具，不重做取数基础设施。范围与身份见[总览](clinical-pathway-workbench-roadmap.zh.md)及[共享模型](clinical-pathway-workbench-model.zh.md)。

## 摘要

医生选择获准科室、时间、诊断与路径版本，查看口径明确的历史统计，点击统计项沿用同一人群条件，并将可追溯观察加入候选区。参考稿修改不改变历史结果；候选不自动成为临床标准或参考稿内容。

<a id="scope"></a>
## 医生任务与范围

起点是 P1 任务范围，结果是一份可复核的人群分析与观察候选。医生可先用历史支持科室讨论而不制定治疗方案，因此 P3 不依赖 P2 的 EMR 组件／完整手工编辑或 P4 AI 操作。

包含路径／诊断筛选、去重住院／执行数、来源状态及保留原因、分母与覆盖、相关病例有界依据、候选区和人群条件沿用。不含自助 SQL、完整病历仓库、真实执行完成率、无来源的疗效／费用收益比较、实时监测、预测模型或自动从历史推导诊疗标准。

<a id="requirements"></a>
## 行为需求与数据归属

P3 拥有分析上下文、统计观察与候选；来源证据保持只读，P1 只引用这些身份，P4 负责把选中候选转换成待采纳修改。

| ID | 必须可观察的行为 | 模型依据 |
| --- | --- | --- |
| P3-01 | 同时显示授权允许范围与本次实际筛选；固定时间起止／时区、科室口径、诊断类别／主诊断／疑似等适用条件。切范围产生新分析上下文，旧结果保留原标签，不自动随任务变。 | M-01、10 |
| P3-02 | 查看路径／诊断和具体版本统计，去重住院与执行次数分开；已完成／退出及非路径治疗按来源枚举解释。未入径比较队列另按入院／出院窗口定义，不能错误套入径时间分母。 | M-01、10；V1 统计语义 |
| P3-03 | 点击某项统计时展示并沿用其完整人群条件和该项条件，可用于病例依据查看或 P4 新参考任务。若只能获得汇总而不能定位成员，沿用条件但说明不是同一不可变成员快照。 | M-01、10 |
| P3-04 | 选中病例仅通过 case_read 读所需类别与片段；显示定义版本、来源时间、实际覆盖、分页和续读进度。未读全、文本不可读或类别未支持不视为不存在，完成标记不证明治疗已完成。 | M-10 |
| P3-05 | 将某项历史观察显式加入候选区，保留来源、分子／分母、人群、时间、覆盖、观察内容和医生备注，可移除／暂缓；去重时保留引用，不跨范围合并成一个频率。 | M-02、10 |
| P3-06 | 所有比例能查看计算口径；分母为 0 显示不适用而非 0% 完成，缺源显示未知而非 0。当前保留原因只作为保留记录，不称完整历史变异次数。 | M-10 |
| P3-07 | EMR 参考编辑、候选移除或 DSH AI 提案不改原统计。刷新查询显式生成新观察，展示各次读取时间及覆盖差别，不拼成全局一致快照。查询失败保留旧结果并清楚标记未更新。 | M-01、10～11 |
| P3-08 | 历史高频项目、低频缺口与医生意见各保留类别。进入 P4 时仅作为待讨论输入，不能自动升为必做、剂量、准入阈值或指南依据。 | M-06、10 |

<a id="dependencies"></a>
## 数据前置与依赖

依赖 P1 的范围、证据身份与私有恢复；取数工具保持既有权限、固定 SQL、有界分页和覆盖语义。某项指标需要读取器尚不支持的检验／检查／手术／给药执行或完整文书时，仅列缺口，不能借本 PRD 扩为新的源接入项目。

目标医院 `1001`／测试科室 `99999` 的数据可能不足以展示某个疾病的治疗方案；历史空样本与查询失败分开。比较不同队列必须分别保存条件和分母；无执行日期或完成时点不能推算平均完成时长。临床任务完成率、疗效及节费结论需要额外来源和业务定义，当前不承诺。

<a id="acceptance"></a>
## 验收场景

验收关注可复核统计和可追溯引用，不以图表数量、病例数量或模型长篇解释作为通过标准。

| 场景 | 可观察通过条件 |
| --- | --- |
| 成功：点统计沿用人群 | 从获准范围的一个状态项打开依据或新参考任务，医院、科室口径、诊断、时间和状态条件完整沿用并可查看，不扩大授权。 |
| 边界：多诊断／多执行 | 一个住院有两诊断和多执行，病例只计一次，执行另计；所用定义版本保留，未入径比较队列不因无执行记录消失。 |
| 成功：观察候选 | 加入一个高频观察后可看来源／口径／时间及临床局限，参考稿未改变；P4 引用它时仍显示“历史观察”。 |
| 失败：来源不可读／分页未完 | 文本缺失、来源未支持及仅第一页都有明确覆盖，不能判没有文书或临床未完成；候选保留这些限制。 |
| 边界：零样本与部分分母 | 真正空队列显示 0 住院，比例不适用；查询失败显示不可用；只读到部分明细时不拿页面数冒充完整分母。 |
| 边界：编辑与再次查询 | 修改参考稿后原统计不变；重新查询产生新时间的观察，来源变化可见，旧候选仍可核对旧口径。 |
| 失败：越权或错误推论 | 其他真实科室读取被拒；系统完成、医嘱存在和当前保留原因不会被展示成真实治疗完成、疗效或累计变异。 |

<a id="stages"></a>
## 分期与后置

P3-A 交付基础路径／诊断及来源状态统计、点统计沿用条件、来源／覆盖与单个观察加入候选，支持 M2。P3-B 完成多候选比较、候选备注／暂缓与更细的病例证据定位，仍只使用既有支持来源。无需先做全面分析门户。

历史样本“试走”留后续探索：须另行确认匹配规则、必需数据、无法判断的处理和验收样本，只报告规则匹配与缺口，不预测疗效或费用收益；不计入 P3-A／B 完成条件。
